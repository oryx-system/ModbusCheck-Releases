# Modbus Check 0.2.0-rc.11

**Excel 주소맵을 실제 통신 확인으로 이어가는 Windows용 Modbus 점검 도구입니다.** BMS·MES와 장비 연동 시 여러 워드의 숫자·문자열·비트 상태를 한 화면에서 살펴보고 기록할 수 있습니다.

이 버전은 **사전 릴리스(RC)**입니다. 정식 안정판이 아닙니다.

- Modbus TCP/IP 및 Serial RTU/ASCII 연결 프로필
- 주소별 숫자·Float·HEX·Binary·ASCII 혼합 표시와 블록 배치
- ASCII 전체 문자열의 연속 워드 쓰기, 바이트·워드 순서와 패딩·전송 값 미리보기
- 16비트 상태와 비트별 설명, 명시적 검토·확인을 거치는 값 편집
- 여러 신호의 트렌드, 점 크기 설정·숨김과 읽기 기록 표·CSV/XLSX 내보내기
- XLSM 주소맵 가져오기·내보내기와 PDU0~1000, 1001주소 표준 양식
- Holding Register FC03 / Input Register FC04, 0·1 기반 참조 표시 선택

Windows x64와 Chrome 또는 Edge가 필요합니다. Node.js 24.22.1과 필요한 라이브러리는 설치 파일에 포함돼 별도 Node 설치가 필요 없습니다. 앱은 연결되지 않은 상태로 시작합니다. 표시는 실제 통신 범위와 0·1 기반 주소를 확인해 사용하세요. Input Register는 읽기 영역이며 앱에서 장치 쓰기를 제공하지 않습니다.

## RC11 변경사항

- 설치 앱의 표준·현재 주소맵을 Windows 저장 창에서 검증된 내장 양식으로 생성합니다. 기존 파일 보호·취소와 Windows 보안 검사를 유지합니다.
- 검증 PC에서 실제 브라우저 다운로드 → 격리 설치 → 새 XLSM 내보내기 → 기존 Office UI 정책으로 열기를 시험해 빨간 출처 차단 없이 매크로 실행을 확인했습니다. 같은 내용의 브라우저 저장 비교 파일은 출처 차단이 유지됐습니다.
- Binary Bit Name·Bit Description과 문서용 ON/OFF 자유 입력을 유지하고, 입력 셀 보호 오류와 ASCII Bytes 1~246 정수 유효성을 수정했습니다.
- 일반 주소는 중성 회색/흰색 교차, Binary 하위16행은 흰색으로 통일했습니다. No·참조·PDU·HEX 값은 가운데 정렬합니다. 워드 맵의 신규 ON/OFF 1비트 선택을 제거했고, 기존 모호한 항목은 임의 변환하지 않습니다.
- 최대 ASCII 편집의 검증 PC 중앙값은 이전 후보 3.44초 → 0.88초로 줄었습니다. 모든 PC와 모든 길이의 속도 향상을 보장하지 않습니다.
- 공식 Node.js 24.22.1로 2026-10-21 보안 수정판을 반영했습니다. 내부 개발 문서·개인 경로는 공개 패키지에서 제외했습니다.

## 시작하기

1. 설치 후 바탕화면 또는 시작 메뉴에서 Modbus Check를 실행합니다.
2. 장비에 맞는 TCP/IP 또는 Serial 연결 조건, 기능코드와 주소 범위를 설정합니다.
3. 현재 받은 값은 중앙 표에서 확인하고 표시 형식·이름을 설정합니다. 표시·이름 변경은 장치에 쓰지 않습니다.
4. 값 변경은 편집창의 현재값·초안·전송 값과 명시적 확인 단계를 거칩니다. 실제 현장 장비의 권한·절차는 사용자가 확인해야 합니다.
5. 주소맵은 Excel로 작성한 뒤 가져오기 미리보기·확인을 거칩니다. 문서 값은 실제 받은 값이나 쓰기 기준값으로 취급하지 않습니다.
6. 표준 양식은 내장 기본 양식이고, 현재 주소맵 내보내기는 현재 정의를 담습니다. 자동 행·비트 확장에는 VBA가 필요합니다.

업데이트 전 사용 중인 장치 연결·기록을 안전하게 마무리하세요. 설치 프로그램은 실행 중 앱을 임의 종료하지 않습니다. 마지막 앱 창을 닫으면 해당 앱이 소유한 서버와 기록을 정리합니다. 기존 설정·기록은 업데이트·제거 시 보존됩니다.

## 알려진 제한

- **다른 PC의 깨끗한 기본 Office 환경과 회사별 매크로 정책은 미검증입니다.** 검증 PC의 기존 Office 설정을 바꿔 통과시킨 것이 아닙니다. 일반 매크로 알림과 서명 필수 정책은 그대로 적용됩니다.
- 이미 인터넷 출처가 붙은 사용자 파일과 브라우저 단독 저장 결과는 그대로입니다. 앱은 출처 표시를 삭제하거나 신뢰 위치·게시자 등록, 전체 매크로 허용을 자동 수행하지 않습니다. 새 저장 경로가 모든 보안 알림을 없애거나 발행자 신뢰를 부여한다고 보장하지 않습니다.
- 설치 EXE와 VBA 프로젝트는 서명되지 않았습니다. Windows의 평판 경고가 나타날 수 있습니다. 공식 배포 파일과 SHA256을 확인하세요.
- 실제 PLC·현장 COM 호환 시험은 별도입니다. 자동 검증은 앱 소유의 로컬 모의·가상 통신으로 진행했습니다. 현장 장비에 임의 연결하거나 쓰지 않았습니다.
- 이전 Float64 전체 멈춤 신고는 재현되지 않아 모든 환경의 완전 해결로 단정하지 않습니다.
