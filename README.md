# Modbus Check

> **0.2.0-rc.7 사전 공개 · Windows x64**
> [설치 파일 다운로드](https://github.com/oryx-system/ModbusCheck-Releases/releases/download/v0.2.0-rc.7/ModbusCheck-0.2.0-rc.7-Setup-win-x64.exe) · [릴리스와 알려진 제한](https://github.com/oryx-system/ModbusCheck-Releases/releases/tag/v0.2.0-rc.7) · [SHA256](https://github.com/oryx-system/ModbusCheck-Releases/releases/download/v0.2.0-rc.7/SHA256SUMS.txt)

**Excel에서 작성한 주소맵을 불러와 통신 확인과 기록으로 이어가는 BMS·MES 실무용 무료 도구입니다.**

제공된 Excel 주소맵 양식에 주소·자료형·설명·비트 설명을 작성하고, 미리보기·검증 결과를 확인한 뒤 앱으로 불러옵니다. 같은 내용을 다시 입력하는 수고를 줄이고, 장비의 수신값 확인부터 트렌드·읽기 기록까지 이어서 작업할 수 있습니다.

- 주소·자료형·설명·비트 설명을 이어 쓰는 Excel 주소맵 가져오기/내보내기, 빈 표준 양식의 PDU0~500 총501주소
- Binary 비트 설명 직접 입력과 다중 워드 후속 행 보호를 지원하는 XLSM 양식
- Modbus TCP와 시리얼 RTU/ASCII 연결 프로필
- 주소별 정수·Float·HEX·Binary·ASCII 혼합 표시와 다중 워드 묶음
- ASCII 전체 문자열, 바이트/워드 순서·패딩·전송 워드 미리보기
- 16비트 상태와 비트별 이름·설명, 개별 비트 편집
- 여러 신호의 트렌드, 점 크기 조절·숨김과 설정 유지
- 가로형 읽기 기록 표와 CSV/XLSX 저장

Windows x64에서 사용합니다. Chrome 또는 Edge가 필요하며 Node 런타임과 앱 라이브러리는 설치 파일에 포함됩니다. 설치 후 앱을 실행하면 연결되지 않은 상태에서 시작합니다. 회사망/장비의 주소·포트·통신 조건을 확인해 직접 설정하세요.

## 기본 사용

1. 설치 후 바탕화면 또는 시작 메뉴의 Modbus Check를 실행합니다.
2. Excel 주소맵 양식에 주소·자료형·설명·비트 설명을 작성하고, 앱의 미리보기·검증 결과를 확인한 뒤 불러옵니다.
3. TCP/IP 또는 Serial 연결 조건과 읽을 주소 범위를 설정하고, 받은 값을 주소맵과 비교합니다.
4. 문자열·비트 값을 변경할 때 현재 받은 값과 편집 초안을 비교하고 전송값을 검토·확인합니다. 표시나 이름 편집만으로는 장비에 쓰지 않습니다.
5. 필요한 신호를 트렌드에 추가하거나 읽기 기록을 저장합니다.
6. 주소맵을 수정할 때는 Excel로 내보내고 미리보기·확인 후 다시 불러올 수 있습니다. 파일 값은 실제 수신값으로 취급하지 않습니다.

XLSM의 자동 행 생성·잠금 변경에는 Excel의 매크로 실행이 필요합니다. 조직의 정책을 따르세요. 앱 가져오기는 VBA를 실행하지 않습니다. 일반 Excel ‘다른 이름으로 저장’으로 XLSX를 만들 수 있으며 별도 전달용 변환 버튼은 없습니다.

## 사전 공개 범위와 보안 안내

이 버전은 0.2.0-rc.7 사전 공개본입니다. 단위241개, Excel 왕복과 격리 설치·업데이트·제거·재설치 검증을 거쳤습니다. 실제 PLC/현장 COM 검증은 별도로 필요하며, 보고된 Float64 전체 멈춤은 재현되지 않아 완전 해결로 단정하지 않습니다. 설치 EXE는 코드 서명되지 않았습니다.

Node.js 24.22.0을 포함합니다. 2026-10-20 UTC 확인 시 [Node 공식 공지](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases)가 예고한 10월21일 전후의 HIGH 보안 수정본은 아직 출시되지 않았습니다. 해당 수정이 적용되었다고 주장하지 않습니다. 현재 공지에는 구체적인 앱 영향과 악용 경로가 공개되지 않아 이 앱이 영향 없다고 단정하지도 않습니다. 공식 수정본은 검토·회귀 후 후속 버전에 반영할 예정입니다.

[공개 릴리스](https://github.com/oryx-system/ModbusCheck-Releases/releases)에서 버전과 SHA256을 확인하세요.
